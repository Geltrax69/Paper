# Shotgun modeling reference

The turnaround sheet interprets the shotgun concept in six exterior views: left, right, top, front, rear, and three-quarter. The result is a stylized variant rather than an exact reconstruction of the gameplay image.

Unseen surfaces are interpreted because the source only shows a first-person angle. The top view incorrectly suggests side-by-side tubes, while the side, front and three-quarter views show vertically stacked tubes. Use the front and side views as the main shape reference and resolve the top silhouette to match them. Bottom and rear three-quarter views are not included. An attempted eight-view correction was rejected by the image tool's safety filter, so this sheet is retained with the limitation documented.

## Blender setup

1. Add the sheet with Add > Image > Reference.
2. Duplicate the reference image for the front, side and top working planes. Adjust each reference image's placement and scale to align its relevant view with your blockout.
3. Start from the side silhouette: stock and grip, receiver, fore-end, then the paired barrel forms. Check width from the top and front views.
4. Keep those exterior groups as separate objects until the proportions agree across the main views.
5. Add bevels and larger surface seams before applying the ink outlines and crosshatching.

Use the orthographic silhouettes to guide shape and the three-quarter views to understand volume. Choose one side silhouette as the primary proportional reference if views disagree.
